# Mark's project scope

This is an NBA prediction app for friends.

Mark's priorities are:

- Correct game dates and rosters.
- Chances that are honest about uncertainty.
- No misleading VALUE labels.
- A fast website.
- An honest record of whether picks were right.

Keep personal tracking simple: won, lost, or waiting for the game results.
An unplayed player or tied result stays out of the win/loss count.
Do not add stakes, bankrolls, payments, refund calculations, profit totals or cash-out tracking unless Mark explicitly asks.
Keep old records. Do not make bookmaker payment rules a release requirement for this prediction app.

Use short, simple English with Mark and with other coding assistants.
Do not publish to the live website without Mark's approval.
